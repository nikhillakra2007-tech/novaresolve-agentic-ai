# Frontend Design Standard: Scroll-Craft

Whenever developing frontend code, landing pages, or web interfaces:
1. **Always use the `scroll-craft` skill** (located in `.agents/skills/scroll-craft` and global `config/skills/scroll-craft`).
2. Treat scroll as a timeline (wheel as scrubber, page as cinematic experience with real semantic text).
3. Implement dimensional hero layering (independently moving background, subject, foreground, and atmospheric planes).
4. Do not use generic, flat, or claymation template patterns. Use token-driven design, genuine alpha cutouts, restrained motion, responsive mobile art direction, and visual verification.
